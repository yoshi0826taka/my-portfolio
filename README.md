# yoshi0826taka Portfolio

Java、Spring Boot、React、MySQLを中心に、制作物とスキルを整理して見せるためのポートフォリオサイトです。

## 公開ページ

- GitHub Pages: https://yoshi0826taka.github.io/my-portfolio/

## 掲載している制作物

### Task-ManagementSystem

Java Servlet / JSP / MySQLで作成したタスク管理システムです。
ログイン、タスク登録・編集・削除、コメント管理、マスタ参照を実装しています。

- Repository: https://github.com/yoshi0826taka/Task-ManagementSystem
- Keywords: Java, Servlet, JSP, DAO, DTO, MySQL, Maven

### weight_log

Spring Bootで作成している体重記録アプリです。
REST API、JPA、DTO、BCrypt、JWT、OpenAPIを取り入れ、バックエンド設計と認証処理を学習しています。

- Repository: https://github.com/yoshi0826taka/weight_log
- Keywords: Java, Spring Boot, JPA, Spring Security, JWT, MySQL, OpenAPI

### my-portfolio

このポートフォリオサイトです。
Reactコンポーネント分割、レスポンシブ対応、GitHub Pages公開まで対応しています。

- Repository: https://github.com/yoshi0826taka/my-portfolio
- Keywords: React, Vite, CSS, GitHub Pages

## 技術スタック

- React 18
- Vite
- CSS
- GitHub Pages

## ローカル実行

```bash
npm install
npm run dev
```

## ビルド

```bash
npm run build
```

## 見せ方の方針

- スキルを自己評価の点数ではなく、制作物とセットで示す
- GitHubで読んだ人が、何を作ったか、どの技術を使ったか、どこを改善中か分かるようにする
- 学習内容だけでなく、再現性のあるREADMEやビルド確認も成果物の一部として扱う
